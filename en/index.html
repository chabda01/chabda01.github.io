Flagship project — June 2026

Zappy: three programs that have to understand each other

The end-of-second-year project: a networked game where teams of autonomous drones compete for resources to reach the highest elevation level. Three executables, three languages, one protocol.

G-YEP-400-COT-4-1

Zappy

The most interesting constraint in the brief: the AI clients have no communication channel outside the game. All team coordination — regrouping, knowing who is missing, triggering a multi-player incantation — travels only through the sound messages broadcast by the server.

Server — C++

One loop, every client

World, map, players and command queues behind a non-blocking server that holds every client on a single event loop, with an adjustable game clock.

AI — Python

One state machine per drone

Each drone is an autonomous process cycling between surviving, collecting and incanting. The team reproduces through the game's Fork command and regroups using a custom broadcast encoding.

GUI — C++ / OpenGL

24 hand-written shaders

Real-time visualisation of the world: sand terrain, animated water, star field, skeletally animated characters, auras and incantation halos — each effect with its own vertex / fragment pair.
