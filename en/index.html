June 2026 · end-of-second-year project

Zappy

A networked game where teams of autonomous drones compete for resources to reach the highest elevation level. Three executables, three languages, one protocol — and the rule that changes everything: the drones have no way of communicating outside the game.

Server — C++

One loop, every client

The world, the map, the players and their command queues behind a non-blocking server that holds every connection on a single event loop, with an adjustable game clock.

AI — Python

A state machine per drone

Each drone is an autonomous process cycling between surviving, collecting and incanting. The team reproduces through the game's Fork command and regroups using a sound-message encoding we had to invent.

Rendering — C++ / OpenGL

Twenty-four shaders

Sand terrain, animated water, star field, skeletally animated characters, auras and incantation halos. Every effect has its own vertex and fragment pair, written by hand.

All team coordination — regrouping, knowing who is missing, triggering an incantation together — travels only through the sounds the server broadcasts. That constraint took up most of my time, and it was by far the most interesting part.
