Compétences+

Une plateforme qui remplace le CV classique par une courte vidéo de présentation et un badge de certification (Bronze, Argent, Or), obtenu après un questionnaire d'aptitudes transversales. Trois espaces : candidat, recruteur, admin.

Le projet s'est appelé ProfilsActifs jusqu'au 9 septembre 2026 ; sur décision du cabinet client, il s'appelle depuis Compétences+, partout et sans variante — j'ai gardé ce nouveau nom ici. Le frontend d'origine est déjà écrit en HTML/CSS/JS natif, sans aucune dépendance : cette page en reprend l'essentiel tel quel (mêmes règles, mêmes comptes de test). Le vrai backend (Node/Express/Prisma/MySQL) n'est pas branché ici : je l'ai remplacé par un petit module JavaScript qui simule les mêmes réponses en mémoire, avec des profils candidats fictifs, inventés pour cette page.

—

Aucune donnée de ce service n'est utilisée pour déterminer vos droits ni le montant de vos allocations. — bandeau réel, affiché sur tous les écrans candidat du vrai produit

          Comptes de test (README §7 du dépôt)

            Mot de passe commun : motdepasse123. Aucune vraie authentification ici — c'est juste pour choisir un rôle.

            Réel / inventé

            5 profils candidats viennent du vrai jeu de test du dépôt (backend/prisma/seed.js). Les autres sont inventés pour cette démo — noms fictifs, personne réelle derrière.

            Comment tester

            1. Passez le questionnaire. Dans l'espace candidat, choisissez « Jean K. » (aucun badge pour l'instant) et cliquez sur « Passer le questionnaire de certification ». Les 20 questions sont les vraies, reprises de certification/questions.v1.json.
            2. Regardez le badge apparaître. Le score se calcule avec la même formule que le serveur réel ; le badge (Bronze, Argent ou Or) suit directement le barème du vrai projet.
            3. Cherchez un profil côté recruteur. Filtrez par secteur, ville ou badge, puis ouvrez une fiche et cliquez sur « Contacter » ou « Mettre en favori ».
            4. Revenez côté candidat. Une notification de cette interaction est arrivée sur le profil que vous venez de contacter — c'est une règle du vrai produit.
            5. Modérez, côté admin. « Romuald Dossou » attend d'être validé, et une vidéo attend aussi sa modération : une fois validés, ils deviennent visibles côté recruteur — pas avant.

            Comment ça marche

            Le score ne se devine pas : chaque option d'une question vaut 0, 1 ou 2 points. Le score final est le rapport entre les points obtenus et le maximum possible, ramené sur 100.

            Ce qui change par rapport au vrai site

            Le vrai frontend parle à une API Node/Express qui lit et écrit dans une base MySQL via Prisma ; ici, un module JavaScript en mémoire (core.js + donnees.js) tient ce rôle, sans aucun serveur. Toutes les règles reproduites viennent du code source du dépôt : le calcul du score et les seuils de badge (questionnaire.service.js, seed.js), le filtre recruteur (profil.service.js, recruteur.js), et le fonctionnement de la modération (admin-moderation.js). Ce qui manque : la vraie vidéo (zone factice, aucun fichier hébergé), l'inscription, et tout ce qui touche à un vrai compte.

            À quoi ça sert en entreprise

            Recrutement sans CV

            Évaluer une aptitude transversale avec la même grille pour tout le monde, plutôt que de comparer des CV écrits très différemment.

            Modération avant publication

            Un profil ou une vidéo n'est visible qu'après validation : utile pour tout catalogue public qui accepte du contenu déposé par des usagers.

            Notifier sans exposer de chiffre public

            Le candidat sait qu'un recruteur l'a contacté ou mis en favori, mais ce compteur reste privé — aucun classement par popularité n'est possible.

            Ce que ce projet montre

            Un frontend statique sans dépendance branché sur une vraie API REST, des règles métier qui viennent du cabinet client, et un travail d'équipe (répartition front/back, revue technique, changement de nom à deux jours de l'échéance).
