NanoTekSpice

Un simulateur de circuits logiques. On décrit un circuit dans un fichier texte : ses composants, puis ses fils. Le programme le monte, puis calcule ses sorties à chaque tick, avec trois états possibles : 0, 1 ou indéfini.

Le projet d'origine est écrit en C++, à deux. Cette page en est une version web : j'ai réécrit les mêmes règles en JavaScript, avec le même format de fichier et les mêmes commandes, pour qu'elles tournent dans votre navigateur. Le schéma, le chronogramme et le clic sur les entrées sont des ajouts de cette page.

Comment tester

    
    
      
  1. Cliquez sur « Jouer le scénario ». L'additionneur est chargé. Les commandes se tapent toutes seules dans le shell : 1 + 1 donne s: 0 et cout: 1. Les fils à 1 passent en doré.
    2. 
      
  2. Cliquez sur une entrée du schéma. Les pastilles à gauche (a, b, cin) changent de valeur. Le shell montre la commande équivalente, puis le circuit se recalcule.
    3. 
      
  3. Tapez dans le shell. Essayez a=U, simulate, puis display. Une entrée indéfinie rend indéfinies les sorties qui en dépendent.
    4. 
      
  4. Lancez l'horloge. Choisissez « Horloge », puis « Jouer le scénario ». La commande loop fait tourner les ticks. Réglez la vitesse, arrêtez avec le bouton ou Ctrl + C.
    5. 
      
  5. Cassez le fichier. Dans l'éditeur, écrivez and seul sur une ligne, ou reliez un composant qui n'existe pas. Le message d'erreur du vrai programme s'affiche, et la ligne est marquée en rouge.
    6. 
    

  

  

    
Comment ça marche

    
Le programme lit le fichier ligne par ligne. Dans .chipsets:, chaque ligne donne un type et un nom : une fabrique crée le bon composant. Dans .links:, chaque ligne relie deux broches.

    
    
À chaque simulate, le tick avance de 1. Les valeurs tapées sont appliquées, les horloges s'inversent, puis chaque sortie demande sa valeur au composant branché sur elle. Ce composant demande à son tour à ses propres entrées, et ainsi de suite.

    
Les portes calculent avec trois états. Un AND avec une entrée à 0 répond 0, même si l'autre est indéfinie. Sinon, une entrée indéfinie donne une sortie indéfinie.

    
Les boucles

    
Si un fil ramène la sortie d'un composant vers sa propre entrée, le calcul tournerait sans fin. Chaque composant note donc qu'il est « en cours de calcul ». Si on lui redemande une valeur pendant ce temps, il répond « indéfini » et le calcul s'arrête. Le circuit « Boucle » le montre.

    
Limite connue du projet : cette marque est posée par composant, pas par broche. Deux portes d'une même puce branchées l'une derrière l'autre donnent donc « indéfini ». C'est le cas du fichier example.nts du projet. La page reproduit ce comportement tel quel. Le simulateur ne garde pas non plus de mémoire d'un tick à l'autre : une bascule ne retient pas sa valeur.

À quoi ça sert en entreprise

  

    
Tester une logique avant de la câbler
Un vote « 2 capteurs sur 3 » ou un verrouillage de sécurité se vérifie sur toutes les combinaisons d'entrées, sans matériel.

    
Décrire un système dans un fichier texte
Le même principe sert aux fichiers de configuration : un format simple, un parseur strict, et des erreurs qui disent où est le problème.

    
Ajouter un composant sans toucher au reste
Chaque composant suit la même interface et passe par une fabrique. C'est la base d'un moteur de règles ou d'un système de plugins.
